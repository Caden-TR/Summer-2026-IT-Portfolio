# Portable Cyber Security Lab Setup

## Overview

This side project documents the creation of a portable Linux-based IT and cyber security lab environment using a Dell Latitude E6320 laptop.

The purpose of this lab is to provide a lightweight environment for practising Linux administration, networking, troubleshooting, and security tooling.
