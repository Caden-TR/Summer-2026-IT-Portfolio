## Overview

This project focused on building a solid understanding of networking fundamentals through both theory and practical exercises. During the week I explored how devices communicate across networks, built a simple LAN in Cisco Packet Tracer, analysed network traffic using Wireshark, and completed a structured troubleshooting exercise.

The project combines technical knowledge with practical evidence, forming the first stage of my Summer 2026 IT Portfolio.

## Objectives

- Understand core networking concepts.
- Learn how devices communicate across a LAN.
- Configure and test a basic network using Cisco Packet Tracer.
- Analyse real network traffic using Wireshark.
- Develop structured troubleshooting skills.
- Produce professional documentation suitable for a GitHub portfolio.

## Technologies Used

- Cisco Packet Tracer
- Wireshark
- Visual Studio Code
- Git & GitHub
- Markdown

## Implementation

During this project I completed:

- Networking theory covering LANs, WANs, switches, MAC addresses, IPv4 addressing, subnet masks, ARP, routers, default gateways, the OSI Model, and the TCP/IP Model.
- Built and tested a simple LAN in Cisco Packet Tracer.
- Verified communication using ICMP ping tests.
- Investigated the MAC address table using Cisco IOS commands.
- Captured and analysed DNS traffic using Wireshark.
- Captured and analysed the TCP three-way handshake.
- Completed a practical network troubleshooting exercise by diagnosing and correcting an IP addressing fault.

## Testing

The completed network was tested using ICMP ping commands to verify successful communication between devices.

Wireshark captures were used to confirm:

- DNS requests and responses.
- TCP three-way handshake.
- ARP communication.

All practical tasks were successfully completed and documented.

## Troubleshooting

A deliberate IP addressing fault was introduced into the Packet Tracer network to simulate a real-world configuration issue.

The problem was diagnosed using network testing and IP configuration checks before correcting the incorrect address and verifying successful communication through additional ping testing.

## Security Considerations

Although this project focused primarily on networking fundamentals, several security concepts were introduced throughout the practical work.

These included:

- Understanding the purpose of MAC addresses and IP addresses.
- Using subnetting to reduce broadcast domains.
- Analysing network traffic with Wireshark.
- Recognising how incorrect network configuration can affect availability and connectivity.

These concepts provide a foundation for more advanced security topics later in the portfolio.

## Reflection

This project strengthened my understanding of how devices communicate across a network and improved my confidence using Cisco Packet Tracer and Wireshark.

The practical exercises reinforced the networking theory through hands-on configuration, traffic analysis, and troubleshooting. Producing professional documentation alongside each task also helped develop the documentation skills expected within IT and cyber security roles.

This project provides a solid foundation for the more advanced networking topics covered in Week 2, including subnetting, VLANs, routing, and network segmentation.
